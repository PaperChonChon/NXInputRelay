# NXInputRelay application metadata

The NRO's NACP title is `NXInputRelay`, its author is
`NXInputRelay contributors`, and its display version is set by `VERSION` in
`build.py`. Original RecurCIV and Plume attribution and licensing remain
preserved in the credits and legal notices. The utility description shown in the application is
`USB Keyboard and Controller Utility`. The installed `nacptool` and libnx NACP
structure do not provide a separate application-description field, so this
description is not advertised as NACP metadata.

`assets/nxinputrelay-icon.jpg` retains the original RecurCIV artwork using the project's
Outfit font; its SIL Open Font License is in `assets/Outfit-OFL.txt`. The
original Plume icon and existing copyright and license notices are retained.
